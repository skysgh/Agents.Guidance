# Conventions - Registries 

Apply these conventions when creating or maintaining inventories of dependencies, certificates, licences, subscriptions, releases, budgets or other governed records.

Extending Documentation Conventions,
several Registries are developed manually or by automation, and managed by different Stakeholders:

```
Maintainers:
  Certificate Registries		    # replace before integration fails
  License Registries			      # 
  Subscription Registries		    # 
  Dependency Version Registries # keep versions secure and supported where possible
Change:
  Release Schedules				      #
Delivery:
  Budget						            #
      
```
