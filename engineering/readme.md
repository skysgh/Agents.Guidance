# Engineering Guidance

This domain contains portable engineering guidance for people and agents.

It explains how to design, build, test, operate and evolve services that matter beyond a single short-lived script or team-only tool.

## Two routes

- [Human guidance](./humans/readme.md) explains the problem, concepts, examples and shared design in accessible language.
- [Agent guidance](./agents/readme.md) provides compact, task-selective rules and routes to the portable conventions.

## Structure

The human and agent routes describe the same engineering intent for different reading needs:

```text
engineering
  -> humans
      -> orientation, palette, examples and glossary
  -> agents
      -> conventions and precise task rules
```

Human documents explain why and show what the design means. Agent conventions state what must be done. They should remain aligned without duplicating each other.
